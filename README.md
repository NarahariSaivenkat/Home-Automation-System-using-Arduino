🏠 Home Automation System using Arduino
📌 Overview

This project demonstrates a microcontroller-based home automation system developed using Arduino. The system automates basic home operations by interfacing sensors and actuators, improving convenience and efficient resource usage. The project was simulated using PicsimLab to validate functionality before hardware implementation.

🎯 Objectives

To automate basic home appliances using a microcontroller

To interface environmental sensors with Arduino

To understand real-time monitoring and control in embedded systems

🛠️ Technologies & Tools

Arduino Microcontroller

Embedded C

Arduino IDE

PicsimLab (Simulation)

🔌 Components Used

LDR (Light Dependent Resistor)

Temperature Sensor

Water Tank (level monitoring/control concept)

Actuators (simulated)

⚙️ Features

Automatic control based on sensor inputs

Light control using LDR

Temperature-based automation logic

Simulation-based validation

🧪 Simulation

The complete system was simulated using PicsimLab

Verified sensor readings and control logic

🚀 How to Run

Open Arduino IDE

Load the source code

Simulate the circuit in PicsimLab

Observe automation behavior based on sensor values

📚 Learning Outcomes

Arduino programming using Embedded C

Sensor interfacing and automation logic

Simulation and debugging using PicsimLab

📁 Project 2: Washing Machine Automation (PIC16F877A)
🧺 Washing Machine Automation using PIC16F877A
📌 Overview

This project involves designing and programming an automated washing machine control system using the PIC16F877A microcontroller. The system manages different washing operations through structured embedded C programming and was validated using simulation tools.

🎯 Objectives

To design an automated washing machine controller

To understand embedded system workflow using PIC microcontrollers

To implement real-time control logic

🛠️ Technologies & Tools

PIC16F877A Microcontroller

Embedded C

MPLAB X IDE

XC8 Compiler

MPLAB Code Configurator (MCC)

PicsimLab

⚙️ Features

Automated washing cycle control

Time-based operation logic

Modular and structured Embedded C code

Simulation-tested design

🧪 Simulation

Simulated using PicsimLab

Verified washing sequence and timing behavior

🚀 How to Run

Open MPLAB X IDE

Configure peripherals using MCC

Compile the code using XC8 compiler

Load HEX file into PicsimLab

Run the simulation and observe operation

📚 Learning Outcomes

Hands-on experience with PIC16F877A

Embedded C programming for real-time systems

Peripheral configuration using MCC

Debugging and simulation skills
